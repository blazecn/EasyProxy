# macOS 原生风格控制中心重设计

## 目标

将 EasyProxy 当前 2×2 等分卡片网格布局，重新设计为 macOS 原生风格（系统设置.app）的侧边栏 + 内容区布局。

## 设计语言

- 参考系统设置.app 风格：灰白底色、半透明模糊侧边栏、浅蓝选中态
- 字体：SF 风格 (-apple-system)
- 白卡 + 浅灰背景 + 微弱边框
- 圆角统一：侧边栏项 6px，卡片 12px
- 强调色：#007aff (macOS 系统蓝)

## 布局架构

```
┌──────────────┬────────────────────────────────┐
│  侧边栏      │  内容区                         │
│  (224px)     │                                │
│              │                                │
│  [导航]      │  根据侧边栏选中项切换内容：       │
│  总览        │  - 总览：订阅信息卡 + 线路卡片    │
│  线路切换    │  - 线路切换：全屏节点列表         │
│  代理规则    │  - 代理规则：规则列表             │
│              │                                │

│              │                                │

```

## 侧边栏结构（从上到下）

### 导航区
- 三个导航项：总览、线路切换、代理规则
- 选中态：蓝底 (#007aff 12% 透明度) + 蓝色文字
- 每项带圆形图标占位（后续可替换为 SF Symbols 或 lucide 图标）

### 订阅列表区
- 分隔标题 "订阅" + 右侧 "+" 按钮（打开导入表单）
- 列出所有已保存订阅，点击即切换当前订阅
- 当前活跃订阅显示蓝底选中态
- 支持侧滑删除（保留 react-swipeable）
- 导入新订阅时，在列表区域底部展开内联输入框

### 状态区
- 灰色圆角背景块
- 显示连接指示灯（绿点）+ "已连接"/"未连接"
- 显示当前节点名称 + 当前模式

### 开关区
- 系统代理开关：macOS 风格 toggle switch
- TUN 模式开关
- 开启时开关底色变绿 (#34c759)，文字变深色
- 关闭时开关底色灰，文字灰色

## 内容区页面

### 总览页
- 页面标题 + 副标题（显示当前订阅名称）
- 顶栏状态条：IP:端口 · 连接状态 · 格式
- 左侧卡片「订阅信息」：6 项大数字网格展示（剩余流量、重置剩余、套餐到期、节点数量、当前线路、代理模式）
- 右侧卡片「线路」：最近几条节点列表 + "查看全部 →" 链接到线路切换页
- 订阅信息卡底部：重命名 / 删除按钮

### 线路切换页
- 全宽节点列表（grid 布局，auto-fill）
- 每项：节点名 + 延迟/推荐标签
- 选中态蓝底白字
- 与当前实现类似，但适配新视觉风格

### 代理规则页
- 规则列表，等宽字体
- 浅灰背景圆角标签展示每条规则
- 与当前实现类似

## 交互行为

- 点击侧边栏订阅项 → 切换当前订阅（调用 save_subscription），刷新内容区数据
- 侧边栏订阅项侧滑 → 显示红色删除按钮
- 点击订阅区 "+" → 在订阅列表下方展开内联导入表单
- 点击线路卡片 "查看全部" → 跳转到线路切换页
- 代理/TUN 开关 → 即时切换，调用对应 backend 命令
- 代理关闭时，节点切换仍可操作（本地缓存选中），与当前行为一致

## 响应式

- 宽屏 (>860px)：侧边栏 + 内容区标准布局
- 中屏 (720-860px)：侧边栏收窄，卡片间距减小
- 窄屏 (<720px)：侧边栏变顶部 tab bar，内容区单列

## 技术约束

- 保留所有现有功能逻辑（订阅持久化、节点缓存、浏览器预览模式等）
- 保留 react-swipeable 和 lucide-react 依赖
- CSS 变量保持现有 --bg, --panel, --border, --soft, --text, --text-h, --muted, --shadow 命名规范
- 测试文件同步更新以匹配新 DOM 结构

## 不做

- 不引入新依赖（已有 lucide-react 提供图标）
- 不改变 backend (Rust) 任何代码
- 不添加新功能（仅重排现有功能的布局）
- 不实现深色模式自定义（依赖系统 prefers-color-scheme）
